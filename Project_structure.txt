## Installation and Setup

1. Clone this repository
2. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Set up your API keys in the config.py file:
   ```python
   # Your SerpAPI key for Google search
   SERPAPI_API_KEY = "your_serpapi_key_here"
   
   # Your Proxycurl API key for LinkedIn profile data
   PROXYCURL_API_KEY = "your_proxycurl_key_here"
   ```

## Usage

### Full Pipeline

Run the complete pipeline (scrape LinkedIn URLs, get profile data, analyze):

```bash
python main.py
```

### Testing with Random Profiles

Test the profile scraper with 10 random LinkedIn profiles:

```bash
python tests/test_random_profiles.py
```
