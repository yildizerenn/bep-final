| Purpose                                             | Command to type                                                                                        | What it does                                                                                                                                                    |
| --------------------------------------------------- | -------------------------------------------------------------                                          | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Full, wide discovery (no name list)**             | `bash python main.py `                                                                                 | Runs the entire SerpAPI → Proxycurl → analysis pipeline; harvests *any* LinkedIn profile that claims a TU/e degree and outputs anonymised CSV files in `data/`. |
| **One specific graduate**                           | `bash python main.py --search_name "Alice Janssen" ` OR python search_by_name "Alice Janssen           | Builds a focused Google query for that exact name + TU/e, scrapes only the best-matched profile, analyses it, and writes a single-row CSV.                      |
| **Batch list from CSV**                             | `bash python main.py --csv_input names.csv ` OR python search_from_csv --csv_input                     | Reads `names.csv` (columns `first_name,last_name`), tries each name in turn, appends results to `data/batch_analyzed_partial.csv`, and resumes if interrupted.  |
